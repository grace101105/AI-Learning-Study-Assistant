#  Agentic AI Learning & Study Assistant

An intelligent AI-powered learning and study assistant that combines **Agentic AI, RAG (Retrieval-Augmented Generation), 3-Tier Cognitive Memory, and interactive study tools** to provide personalized learning experiences.

### 🚀 Features

* 🤖 Agentic AI with ReAct orchestration
* 📚 RAG-based knowledge retrieval with citations
* 🧠 3-Tier Cognitive Memory
* 🗂️ SM-2 Spaced Repetition Flashcards
* 🎯 Interactive diagnostic quizzes
* 🧩 Interactive Knowledge Graph
* 💻 JavaScript Algorithm Code Sandbox
* ⏱️ Pomodoro Focus Timer
* 📝 Custom study-note ingestion
* 🌙 Dark-themed responsive UI
* 💾 Persistent learner data using LocalStorage

### 🛠️ Technologies

**HTML5 | CSS3 | JavaScript | Tailwind CSS | Agentic AI | RAG | SM-2 | LocalStorage**

### ▶️ Run the Project

Open `index.html` directly in a modern browser, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

This project is designed as a personalized cognitive learning platform for students, combining AI assistance with active recall, spaced repetition, knowledge visualization, and interactive coding tools.
